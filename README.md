Durante o curso de JavaScript da DIO, desenvolvi uma Pokédex interativa que consome dados da PokeAPI, exibindo informações como nome, tipo e imagem dos Pokémon de forma dinâmica.
Esse projeto foi um ótimo exercício para consolidar conceitos fundamentais de JavaScript, como:
Manipulação do DOM
Uso de funções assíncronas com fetch() e Promise.all()
Estruturação de código com módulos JS
Consumo de APIs REST e tratamento de dados JSON
Além de reforçar a lógica de programação, o desafio mostrou como é possível transformar código em algo visual e interativo — ver o resultado rodando no navegador é sempre motivador! 🚀
💻 Tecnologias utilizadas:
 HTML | CSS | JavaScript | PokeAPI
